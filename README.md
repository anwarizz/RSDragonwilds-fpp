# First-Person Camera Mod (UE4SS)

Download [CurseForge Profile](https://www.curseforge.com/members/daoa/projects)

---

## Default Controls
- `V`: Toggle First-Person Camera
- `F6`: Enable First-Person
- `F7`: Disable First-Person
- `F8`: Toggle Head Visibility (Debug)
- `F9`: Dump Character Mesh Components to Console (Debug)

---

## Installation
1. Install **UE4SS** for the game. Find out how to set it up.
2. Once UE4SS is installed, extract the `FirstPersonCamera.zip` folder into your game's UE4SS `Mods` directory:
   `.../Binaries/Win64/ue4ss/Mods/`
3. Launch the game.

---

## Configuration
The default keybinds are already configured in `keybinds.txt`. If you want to change them, edit the file inside the mod root directory:
`Mods/FirstPersonCamera/keybinds.txt`


```ini
toggle=V
first_person_on=F6
first_person_off=F7
toggle_head_debug=F8
dump_mesh_debug=F9
